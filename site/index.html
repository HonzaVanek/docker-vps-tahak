Tři základní principy

Container není virtuální server

Je to izolovaný proces/prostředí nad stejným Linuxovým kernelem. Běží, dokud běží jeho hlavní proces.

Image je receptovaný výrobek

Dockerfile → docker build → image. Z jednoho image může vzniknout mnoho containerů.

Deploy není git pull

git pull změní zdrojáky na serveru. Teprve nový build + nový container změní skutečně běžící aplikaci.

Reverse proxy je před aplikací

Veřejný nginx přijme request, řeší doménu/HTTPS a pošle ho internímu backendu.

Praktický tahák vznikl z jednoho kompletního cvičení: VPS → nginx → Docker → Git → HTTPS → opakovaný deploy.
